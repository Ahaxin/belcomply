PPWR 符合性声明（DoC）：是什么、谁来签

2026年10月12日 · 指南

符合性声明（DoC）是声明您的包装满足 PPWR 设计与可持续性要求的文件。它和 EPR 注册是两回事——两者很容易搞混。下面讲清楚区别。

一句话总结 — 符合性声明是制造商（或其授权代表）出具的文件，声明包装满足 PPWR 对可回收性、再生材料含量、物质限制和标识的要求。它不等于 EPR 注册。

符合性声明是什么

DoC 是制造商对「某类包装满足 PPWR 适用要求」的正式声明——可回收设计标准、再生材料含量目标、受限物质限制，以及标识和标签规则。它就是那句「这包装是合规的」背后站着的文件。

谁来签

由制造商起草并签署 DoC——或者，如果制造商指定了授权代表，则由授权代表代为签署。对没有欧盟实体、身在海外的非欧盟生产者来说，授权代表的角色在这里同样关键：当监管机构或平台索要这份文件时，得有本地可联系的一方能够持有并出示它。

它必须包含什么

一份有效的 DoC 要指明它所覆盖的包装、声明它符合哪些要求、写明制造商的名称和地址，并注明日期、由有权代表制造商的人签字。具体字段跟着 PPWR 的附件走，但原则很简单：必须具体到让市场监管机构能把某类包装追溯到责任方。

DoC 和 EPR 注册——两条不同的线

这是卖家最容易栽的地方。DoC 关乎设计合规——包装本身是否达标。EPR 注册关乎生产者责任——在国家注册表登记、加入生产者责任组织、缴纳用于收集和回收的生态贡献。两者都要做，但它们是两套独立的义务、独立的文件、独立的时限。

什么时候会有人来要

市场监管机构可能在很短时间内索要 DoC，平台也可能先要注册号——但 DoC 才是支撑您对包装所作任何设计声明的依据。手里有一份起草规范、随时可取的 DoC，区别就是快速应答还是手忙脚乱。

实操结论：把 DoC 当成一份活的文件，而不是一次性文件。随包装更新、让授权代表随时可查、在有人索要那天随时能拿得出来。

来源：PPWR（欧盟）2025/40，附件 VIII（符合性声明）。
